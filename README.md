# 🍢 เว็บไซต์ร้านค้ารถเข็น "บักมันม่วง ข้าวเหนียวหมูปิ้ง&ไก่ย่างส้มตำ เตาถ่าน"

เว็บไซต์ร้านอาหารแนว Street Food สไตล์ไทยแท้ ออกแบบบรรยากาศเหมือน **รถเข็นขายส้มตำ-หมูปิ้งข้างทาง** พร้อมลูกเล่นเตาย่างถ่าน ควันลอย และระบบตะกร้าสินค้าสั่งอาหาร

---

## 🎨 จุดเด่นการดีไซน์ (Design Highlights)
1. **ผ้าใบกันแดดลายทาง (Awning Canvas):** ลายทางแดง-ขาว-ส้ม พร้อมระบายขอบหยักแบบรถเข็นสตรีทฟู้ด
2. **ป้ายชื่อร้านไวนิลย้อนยุค:** สีสันจัดจ้าน ตัวหนังสือตัดขอบคมชัด สไตล์ป้ายร้านข้างทาง
3. **เตาปิ้งย่าง Interactive (Hot Charcoal Grill):** มีประกายถ่านแดง ควันลอย และเมนูหมูปิ้ง-ไก่ย่างกำลังย่างฉ่าๆ **สามารถคลิกที่ของบนเตาเพื่อคีบใส่ถุงได้ทันที!**
4. **สวิตช์ไฟนีออนหน้ารถเข็น:** สามารถคลิกเปิด-ปิดไฟนีออนใต้หลังคารถเข็นได้
5. **ถุงสั่งอาหาร & กิมมิคไทยบ้าน:**
   - ป้ายลังกระดาษแปะโปรโมชัน (ซื้อหมู 10 ไม้ แถมข้าวเหนียว 1 ห่อ)
   - เลือกระดับความเกรียม (เกรียมกำลังดี / ไม่เกรียม)
   - เลือกน้ำจิ้ม (แจ่วมะขามเปียก / น้ำจิ้มไก่หวาน / ทั้งสองอย่าง)
6. **ระบบชำระเงิน Thai QR PromptPay จำลอง:** สแกนจ่ายพร้อมคำนวณยอดเงินอัตโนมัติ
7. **ปุ่มกดสั่งส่งเข้า LINE:** แปลงรายการออเดอร์เป็นข้อความพร้อมส่งเข้า LINE ร้านค้าทันที
